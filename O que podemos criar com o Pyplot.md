##  O que podemos criar com o Pyplot?

```text
O pyplot é um módulo do Matplotlib usado para criar e configurar gráficos.

```


Pense no `pyplot` como uma caixa de ferramentas de desenho:

* os dados são as informações;
* o gráfico é o desenho;
* título, cores, legenda e eixos são os acabamentos.

A documentação oficial apresenta diversos [tipos de gráficos do Matplotlib](https://matplotlib.org/stable/plot_types/index.html).


## Principais tipos de gráficos

| Tipo               | Função                        | Quando utilizar                                   |
| ------------------ | ----------------------------- | ------------------------------------------------- |
| Linhas             | `plt.plot()`                  | Evolução ao longo do tempo                        |
| Barras verticais   | `plt.bar()`                   | Comparar categorias                               |
| Barras horizontais | `plt.barh()`                  | Comparar categorias com nomes longos              |
| Dispersão          | `plt.scatter()`               | Observar relação entre duas variáveis             |
| Histograma         | `plt.hist()`                  | Analisar a distribuição dos dados                 |
| Setores ou pizza   | `plt.pie()`                   | Mostrar proporções de um total                    |
| Boxplot            | `plt.boxplot()`               | Identificar mediana, quartis e possíveis outliers |
| Área               | `plt.fill_between()`          | Destacar a área entre valores                     |
| Área empilhada     | `plt.stackplot()`             | Mostrar composição ao longo do tempo              |
| Degraus            | `plt.step()`                  | Representar mudanças em intervalos                |
| Hastes             | `plt.stem()`                  | Mostrar valores discretos                         |
| Mapa de calor      | `plt.imshow()`                | Representar matrizes por meio de cores            |
| Contorno           | `plt.contour()`               | Representar níveis de uma superfície              |
| Barras de erro     | `plt.errorbar()`              | Mostrar valor e margem de erro                    |
| Violino            | `plt.violinplot()`            | Comparar distribuições                            |
| Gráficos 3D        | `plot_surface()`, `scatter()` | Representar dados em três dimensões               |
